# Current delivery contracts

This root contains current Feature, JIT, proof, execution and content-evidence contracts consumed by development beneath the durable law in `docs/governance/`. Its routing entrypoint is [`CURRENT_DELIVERY_ROUTER.json`](CURRENT_DELIVERY_ROUTER.json).

These contracts do not become Product, Architecture or Domain authority by being current or durable. Do not create semantic successors to record ordinary implementation choices or Plane status. Record live execution state in Plane project `WELL`.

Foundation Smoke validates this router and its boundary. Changes here route to applicable Application CI without selecting Foundation Full solely because they are delivery contracts.
