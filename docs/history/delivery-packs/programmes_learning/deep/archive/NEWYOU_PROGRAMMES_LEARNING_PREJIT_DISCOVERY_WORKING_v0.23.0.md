# 179. Pass 22 — FP-014 Foundation Programme second-lens pressure test

## 179.1 Scope hard stop

This pass asks only:

1. which Nuwe Jy-derived Programme primitives genuinely generalise to FP-014;
2. which flagship assumptions must remain optional/configured rather than universal;
3. how habits/private reflections/recovery/completion compose across Programmes and HJP;
4. which existing gaps become conditional or more material under the Foundation lens; and
5. whether the second lens requires new Product/Architecture/Domain authority.

It does **not** create FP-014 Phase 7 artifacts, select its exact delivery mode, define its content, choose completion thresholds, design UI/screens, select Resources/tables, or authorise implementation.

## 179.2 Second-lens criterion

The reusable model succeeds only if FP-014 can be expressed without requiring Nuwe Jy-only features.

The safe centre is:

`ProgrammeVersion -> Enrolment/attempt -> explicit requirement/progression/completion semantics`

with delivery-mode-specific composition around it.

For a scheduled/facilitated Programme that composition may include Edition/Cohort/schedule. For evergreen self-paced delivery, a shared Cohort is not required by Product Law.

- Edition;

- Community;

- Programme-specific communications.

Conditional does not mean ungoverned. If activated, the owning Domain and existing gates apply.
