# 97A. Pass-11 correction record

## R11-C01 — Gate-routing precision — IMPLEMENTED

The v0.12.0 sentence stating that current authority is sufficient to enter FP-008 JIT once `OQ-019/OQ-020/OQ-021/OQ-025/OQ-026` are resolved was too broad. It could be read as both:

1. treating those five gates as the complete FP-008 gate set; and
2. requiring each of them to be resolved before FP-008 JIT can begin.

Neither implication is permitted by current Roadmap authority.

The corrected working meaning is:

> Pass 11 has bounded the live/replay semantic questions sufficiently for later FP-008 JIT. FP-008 entry and progression remain governed by the complete current Roadmap and applicable Feature Pack Gate Manifest, not by this Pre-JIT ledger. For the live/replay slice specifically, concrete values and exception paths remain gated by `OQ-019`, `OQ-020`, `OQ-021`, `OQ-025` and `OQ-026` as applicable. This does not imply that those are the complete FP-008 gate set or that every such gate must be resolved before JIT begins.

Roadmap gate classification remains authoritative. In particular, `OQ-020` and `OQ-021` block the affected FP-007 live/replay path and are release gates for FP-008 where applicable; they are not restated here as universal FP-008 JIT-entry gates.
