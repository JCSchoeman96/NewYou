## 3. Preservation assertions

1. Provider resource identity never becomes NewYou occurrence identity.
2. Registration, entitlement, join capability, provider presence, attendance, recording authority, provider capture, governed media, replay publication, replay entitlement and replay consumption remain distinct.
3. Provider identity/role labels never become canonical NewYou identity/role authority.
4. Provider capture never manufactures recording authority or governed media.
5. Governed media never automatically becomes replay publication; publication never automatically grants entitlement.
6. Recording notice != recording permission/current purpose authority; late join and material role/policy change re-evaluate current authority.
7. Historical lawful capture does not create indefinite replay/promotion authority; technical separability is evidence, not legal/Product authority.
8. Current publication eligibility != physical retention.
9. Provider deletion acknowledgement/status != verified governed deletion completion.
10. Full Deletion does not rewrite historical attendance as no-show.
11. Locked Full Deletion timing is preserved: immediate normal-access revocation → **14-day cancellation window** → irreversible execution → verified completion; irreversible completion has no recovery/reconstruction path.
12. Timely deletion cancellation does not resurrect already disposed data, registration, entitlement or provider admission.
13. Replay correction/versioning never rewrites occurrence/attendance history.
14. **Class-dependent correction failure is preserved:** ordinary material V1 may remain current only while still safe/lawful/currently eligible; safety/legal/consent-invalid V1 remains fail-closed when successor processing fails.
15. Promotional clip != replay; clips are not mandatory FP-007 exit scope.
16. Communications delivery != occurrence/access/replay authority.
17. Optional reminder/marketing/convenience roles may not masquerade as mandatory product/safety notices to bypass participant controls.
18. No Live-specific Communications Resource is justified by this discovery; existing Communications ownership and logical MessageIntent/DeliveryAttempt seams are reused unless future governed evidence changes that conclusion.
19. Stale message/link/token/cache/provider state cannot restore withdrawn/revoked authority.
20. No global shared-write Live orchestration Domain or distributed transaction is introduced merely for correctness.
21. Owner-mediated recovery, current-precondition revalidation and crash/restart correctness remain mandatory for must-not-lose consequences.
22. Provider/network I/O remains outside authoritative locks/transactions; queue uniqueness != business idempotency.
23. **Ambiguous provider create must reconcile before repeat** after timeout/restart or idempotency expiry; provider-key expiry never authorises blind duplicate create.
24. EV-002 explicitly retains the current Restream documentation fact that paid live streams are automatically recorded/saved.
25. Absence of a documented Restream disable control remains non-proof that disabling is impossible; OQ-020/OQ-021 controlled confirmation is still required.
26. Cloudflare connected != participant-playable; live-input evidence != video-processing evidence.
27. Deleting a Cloudflare Live Input does not delete existing recordings; representation-complete deletion remains required.
28. Scarce Event Commerce remains outside FP-007.
29. OQ-020 remains open; OQ-021 remains open.
30. OQ-036 applies only to included/promised communications; OQ-017 only when reminders are promised.
31. OQ-029...032 and OQ-014 retain existing applicability; no silent gate reclassification occurred.
32. LIVE-UPD-007 remains unwarranted; LIVE-GAP-015 remains unwarranted.
33. Provider documentation remains evidence only, not controlled proof or gate closure.
34. No default Pass N exists.
35. FP-007 is not selected/Phase-7 authorised by this pack; implementation remains NOT AUTHORISED.
