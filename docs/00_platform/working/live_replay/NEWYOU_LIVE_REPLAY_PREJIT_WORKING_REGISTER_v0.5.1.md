# 4. Accepted Pass-G semantic conclusions

1. Current replay/publication eligibility and physical media retention are independent dimensions; retention never restores delivery authority.
2. Continued retention requires positive scoped authority; provider defaults, historical capture and convenience are not retention bases.
3. Deletion obligation, request, acknowledgement, provider status and verified completion are separate facts.
4. Processor deletion is representation-complete for the governed scope; deleting only the primary replay is insufficient when applicable derivatives/provider copies survive.
5. Unknown external deletion outcome remains unresolved and must be reconciled safely.
6. Duplicate/reordered provider evidence cannot define NewYou terminality by arrival order.
7. Legal hold or another approved retention basis pauses only governed destruction within scope and never restores replay/publication authority.
8. Backup/restore may restore bytes but not authority; current suppression/deletion/withdrawal truth must be reconciled before promotion.
9. Historical provider resources/bindings participate in deletion inventory where applicable.
10. A processor that cannot satisfy approved deletion/retention/evidence requirements is a blocked release path, not a reason to weaken NewYou rules.
11. No `LIVE-UPD-007` is warranted because existing OQ-021/OQ-029/OQ-030/OQ-031 authority/gates already own the missing work.
12. `LIVE-GAP-014` is the correct live-specific provider empirical seam for processor deletion/non-resurrection evidence.
